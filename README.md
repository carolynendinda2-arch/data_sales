# Sales Revenue Prediction Model

**My First Complete Machine Learning Project** 🎉

## Project Overview
This project analyzes sales data for phone accessories across different cities in Kenya. I built a **Random Forest Regressor** model to predict **Revenue** based on product, quantity, unit price, and city.

## Dataset
- **Source**: `data_sales.csv`
- **Rows**: ~10,300 sales records
- **Features**: Order Date, Product, Quantity, Unit Price, City

## What I Did
- **Data Cleaning**: Fixed missing values, converted data types, removed duplicates
- **Feature Engineering**: Created `Revenue` column, used One-Hot Encoding for categorical variables
- **Modeling**: Trained Random Forest Regressor
- **Evaluation**: Achieved perfect R² = 1.0 and MAE = 0.0 on test set
- **Visualization**: Feature Importance & Actual vs Predicted plots

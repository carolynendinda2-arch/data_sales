# Sales Revenue Prediction Model

My First Complete Machine Learning Project

## Project Overview
This project analyzes sales data for phone accessories across different cities in Kenya.
I built a Random Forest Regressor model to predict Revenue.

## Dataset
- Source: data_sales.csv
- Rows: \~10,300 sales records
- Features: Order Date, Product, Quantity, Unit Price, City

## What I Did
- Data Cleaning
- Feature Engineering (One-Hot Encoding)
- Trained Random Forest Regressor
- Model Evaluation (R² = 1.0)
- Created Feature Importance and Prediction plots
